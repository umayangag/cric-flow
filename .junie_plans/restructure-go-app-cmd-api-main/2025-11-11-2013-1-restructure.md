# Plan X: Restructure go-app/cmd/api/main.go into modular files

Parent: none

## Goal
Make the API command easier to read and maintain by splitting routing, handlers, and response helpers into separate files without changing behavior.

## Scope
- Only affects: `go-app/cmd/api/*`
- No behavioral changes; pure refactor.
- Keep package `main` under `cmd/api`.

## Proposed Changes
1. Extract response helpers to `response.go`.
2. Extract HTTP handlers to `handlers.go`.
3. Build router in `server.go` via `newRouter()`.
4. Slim `main.go` to initialization + server start using `newRouter()`.

## Files
- go-app/cmd/api/main.go (simplified)
- go-app/cmd/api/server.go (new)
- go-app/cmd/api/handlers.go (new)
- go-app/cmd/api/response.go (new)

## Tests / Verification
- Compile the module and ensure no build errors.
- Optional: run the server locally and curl endpoints.

- Behavior of migration and DB connection in `main` unchanged.

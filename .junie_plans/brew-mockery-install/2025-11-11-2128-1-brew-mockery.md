# Plan 1: Switch mock generator installation to Homebrew (mockery)

Parent: none

## Goal
Replace all developer guidance and automation that suggests installing mockery via `go install github.com/vektra/mockery/v2@latest` with Homebrew installation (`brew install mockery`). Ensure `make mocks` works with the Homebrew-provided `mockery` binary on PATH.

## Scope
- Update docs and Makefile under `go-app/` only.
- Do not change mock definitions or `.mockery.yaml` content/paths.
- Keep cross-platform note minimal (macOS primary; optional hint for Linux users).

## Proposed Changes
1. Documentation updates
   - Update `go-app/README.md` to instruct `brew install mockery` instead of `go install ...`.
   - Add a brief note: “On Linux/CI, install mockery via your package manager or use `go install` as a fallback.”
2. Makefile improvements
   - Ensure `make -C go-app mocks` uses `mockery` from PATH.
   - Add a preflight check that prints a friendly error with installation hint if `mockery` is missing.
   - Remove any `go install ...mockery...` from Makefile targets if present.
3. Sanity check `.mockery.yaml`
   - No changes expected; just ensure paths align with current usage.

## Files
- go-app/README.md
- go-app/Makefile
- go-app/.mockery.yaml (read/verify only)

## Tests / Verification
- Functional
  - `which mockery` returns a path after installing via Homebrew.
  - `make -C go-app mocks` runs without attempting to install mockery via `go install`.
- Build
  - `cd go-app && go build ./...` succeeds.
- CI/Portability (manual spot check)
  - `mockery --version` runs.

## Acceptance Criteria
- All references in `go-app/README.md` to installing mockery via `go install` are replaced with `brew install mockery` and contain a brief fallback note for non-macOS users.
- `make mocks` and `make -C go-app mocks` succeed when Homebrew-installed `mockery` is on PATH.
- The Makefile contains no `go install github.com/vektra/mockery/...` commands.
- No changes to mock interfaces or `.mockery.yaml`.
- `cd go-app && go build ./...` succeeds.
